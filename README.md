# 开发助手

Chrome/Edge 浏览器扩展（Manifest V3），为云枢（CloudPivot）与氚云（H3Yun）两个低代码平台的在线开发页面提供本地代码抓取、回写与目录协作。

- 作者：凌致

## 功能

- **云枢**：抓取 / 回写前端 HTML/CSS/JS、业务规则（Java）、FromCode.md；按产物配置生成协作文件
- **氚云**：一键抓取（FromCode + 前端 JS + 后端 C#）与一键回写，表单 / 列表双模式
- **目录管理**：File System Access API 本地目录绑定，按页面业务实例记忆、页面间互不串用；页面无绑定时按云枢 / 氚云分别使用各自默认目录；目录名称、目录选择器初始位置和实际读写共用同一目录句柄；历史目录搜索一键恢复，跨标签页同步
- **产物配置**：产物分「抓取产物」与「可自定义产物」两区，可在设置页编辑名称、路径、文件名与默认内容，并支持子目录

### 目录状态规则

1. 页面已有绑定时，页面业务 scope 的目录句柄优先，其他页面最后选择的目录不会覆盖它。
2. 页面没有绑定时，只回退到当前平台的默认目录句柄；云枢和氚云各自独立保存。
3. 页面显示名称、目录选择器 `startIn`、文件读写和权限检查都从同一个有效句柄解析，避免显示目录与实际目录不一致。
4. 设置页默认目录需要通过「浏览」选择并保存句柄；仅手动填写文本不能授予浏览器访问本地目录的权限。

## 产物与目录结构

生成物统一写入同一个目标目录，可含子目录：

| 产物 | 云枢 | 氚云 | 说明 |
| --- | --- | --- | --- |
| FromCode.md | ✅ | ✅ | 字段 / 控件编码上下文，内容用代码块围栏包裹 |
| HTML / CSS / JS | ✅ | ✅ | 前端代码，内容来自页面抓取 |
| 业务规则 Java | ✅ | — | `{类名}.java` |
| 后端 C# | — | ✅ | `{类名}.cs` |
| README.md | ✅ | ✅ | 业务需求，用户维护 |
| AGENTS.md | ✅ | ✅ | 本目录 Agent 规则 |
| `design/` | ✅ 仅建文件夹 | ✅ 含 design-js.md + design-cs.md | 云枢按 Java 类自行建文档；氚云前后端各自成文件 |
| `sql/` | ✅ 仅建文件夹 | — | 业务集成 SQL 脚本 |

## 产物配置规则

- **抓取产物**（FromCode / HTML / CSS / JS / Java / C#）：内容来自页面抓取，设置页只提供开关。
- **可自定义产物**（README / AGENTS / `design/` / `sql/` / `design-js.md` / `design-cs.md` 及用户新建项）：可编辑名称、路径、文件名、开关与默认内容。
- **文件名留空 = 只建文件夹**（`design/`、`sql/` 即此形态）。
- **覆盖策略统一为「补建缺失」**：已存在的文件不会被重新生成，也不会刷新变量。
- **变量仅在首次生成时替换一次**：模板支持 `{{页面地址}}` `{{应用编码}}` `{{表单编码}}` `{{表单名称}}` `{{主表编码}}` `{{平台}}` `{{页面类型}}`。
- **内置产物不可删除**，只能关闭开关；用户新建的产物可删除。顶部「恢复默认」可恢复出厂产物配置。
- 同平台内「路径 + 文件名」重复会互相覆盖，保存时会被拦截。

## 从旧版本升级

旧版 `generatedFiles` 逐字段开关会自动迁移，**沿用老值不重置**：

- `fromCode` / `html` / `css` / `js` / `cs` / `readme` / `agents` 原样沿用
- 云枢 `design` 沿用布尔值（语义由 `DESIGN.md` 变为 `design/` 文件夹）
- 氚云 `design: true` 拆成 `designJs` + `designCs` 两项，均保持开启
- 新增产物：`java` 默认开（原先无条件生成，默认关会造成静默功能回退），`sql` / 云枢 `design` 默认关

**注意**：根目录不再生成 `DESIGN.md`，改由 `design/` 目录承载。已生成的 `DESIGN.md` 不会被删除，可自行处理。
