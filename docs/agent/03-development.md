# 开发规范

## TypeScript

* 优先使用 ES6+ 语法。
* 优先使用箭头函数。
* 字符串统一使用单引号。
* 禁止使用分号。
* 优先使用 `const`，仅在需要重新赋值时使用 `let`，禁止使用 `var`。
* 优先使用类型推断，避免为显而易见的变量重复声明类型。
* 类型和接口命名使用 PascalCase。
* 变量、函数和参数使用 camelCase。
* 避免类型断言（`as`）；确有必要时，应确保断言具有明确的类型依据。
* 函数保持单一职责。
* 单个函数原则上不超过 50 行；超过 50 行但少于 65 行时可视情况保留；达到 65 行及以上时应合理拆分。
* 避免深层嵌套，优先使用提前返回（Early Return）。
* 禁止无意义的注释。
* 禁止保留未使用的变量、函数、导入和依赖。

## 依赖

* 新增依赖前确认现有工具链无法满足需求。
* 优先复用已有依赖。
* 移除依赖前确认源码、测试和构建脚本均无引用。
* 不得把开发依赖误放到运行时依赖，或反之。
* 不手动编辑 `package-lock.json`。
* 不使用 `npm install`、`pnpm install`、`yarn install` 交替改写同一工作区。
* 依赖更新后，根据实际影响执行类型检查、测试和构建。
* 更新依赖导致开发运行环境变化时，重启开发服务器。

## API

* 存在 API 路由时，统一使用 `try-catch` 捕获需要处理的异常。
* API 错误响应使用项目统一格式。
* 避免无意义的重复 `try-catch`。
* 无法处理的异常继续向上抛出或转换为项目统一错误类型。

## 外部输入

外部输入包括：

* Chrome API 返回值。
* `chrome.storage` 数据。
* IndexedDB 数据。
* DOM 数据。
* URL。
* 用户填写的产物配置。
* 注入函数返回值。

使用前进行必要的空值、类型和结构校验。

禁止将：

```ts
JSON.parse()
```

或类型断言直接作为运行时校验的替代方案。

## 错误处理

业务错误使用：

```text
src/lib/errors.ts
```

中的现有业务错误类型。

当前类型：

```text
BusinessError
ValidationError
DirectoryError
```

新增业务错误应使用明确的错误码。

禁止新增长期存在的：

* 裸字符串错误。
* 裸 `Error`。
* 静默吞错。

注入函数使用可序列化结果：

```ts
{ ok: true, ... }
```

或：

```ts
{ ok: false, errorCode, details }
```

调用侧负责转换为日志和 UI 状态。

## 日志

运行时代码统一使用：

```text
src/lib/logger.ts
```

禁止在 `src/` 中散落 `console.*`。

日志级别：

* `debug`：调试信息。
* `info`：正常运行信息。
* `warn`：可恢复降级。
* `error`：不可完成的业务或基础设施失败。

日志不得包含：

* 密码。
* Token。
* API Key。
* 完整请求体。
* 包含敏感查询参数的完整 URL。

优先记录：

* 平台。
* 页面类型。
* scope。
* 错误码。
* 文件相对路径。
* 耗时。

构建和发布 CLI 脚本可使用带 `[build]`、`[package]` 前缀的命令行输出。

## 配置

* 环境相关配置通过环境变量或项目配置管理。
* 新增环境变量时说明来源、开发/构建阶段、默认值和缺失行为。
* 不得把密钥通过环境变量打包进前端代码。
* 不提交包含真实敏感信息的 `.env` 文件。

## 构建

生产构建：

```bash
npm run build
```

构建脚本负责：

* 清理 `dist/`。
* 重建 `dist/`。
* 拷贝 HTML/CSS/manifest/assets。
* 使用 esbuild 生成 Popup、Options、Background 入口及 source map。

发布压缩包：

```bash
node scripts/package.mjs
```

必须先完成构建。

打包脚本依赖系统 `tar`，生成物位于：

```text
releases/
```
不需要生成更新文件说明。
不得直接修改生成的发布压缩包。

## API / 平台配置

GitHub 更新检查地址和平台域名映射属于代码配置。

修改时同步检查：

* 超时。
* 域名匹配。
* 权限。
* 日志脱敏。

禁止把运行时 Token 写入源码或存储。
