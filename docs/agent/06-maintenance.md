# 文档、删除与清理规范

## 文档

* Bug 修复和新增功能更新 `BUG_FIXES.md`。
* `BUG_FIXES.md` 只记录简要的最终结果。
* `BUG_FIXES.md` 每次新版本的改动都会删除掉已发布的版本的改动
* 每次改动仅在产生长期有价值的信息时，在 `docs/memory/` 创建当日日期文件。


## README

仅在改动影响以下内容时更新 `README.md`：

* 项目使用方式。
* 安装方式。
* 配置方式。
* 用户可见功能。
* 用户操作流程。
* 对外行为。

内部重构和纯实现调整无需更新 README。

## 删除

* 仅删除能够确认无用途的文件或代码。
* 删除项目原有文件时，优先移入系统回收站。
* 本次任务创建且确认无用途的临时文件可以直接删除。
* 不使用 `-Force` 等非必要强制参数。
* 不得删除与当前任务无关的用户文件。

## 收尾检查

任务结束前检查：

* 废弃代码。
* 不可达代码。
* 临时文件。
* 冲突残留。
* 无关生成物。
* 未使用导入。
* 未使用依赖。

不得为了“清理代码”扩大当前任务范围。
